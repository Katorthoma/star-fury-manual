# Status and color reference

## Universe Browser

| Color | Meaning |
|---|---|
| Blue | Newbie |
| Green | Vacation |
| Purple | Disbanding |
| Orange | your empire |
| Black | dead |

## Universe News

| Color | Meaning |
|---|---|
| Blue | peace treaty |
| Green | neutral treaty |
| Red | war declaration |
| Orange | alliance disbanded or defeated |

## Alliance News

| Color | Meaning |
|---|---|
| Orange | attack from your alliance |
| Blue | failed enemy attack |
| Yellow | successful enemy attack |
| Red | empire or Boss defeated |
| Purple | Boss reward notification |
