# Pre-war checklist

- [ ] Important ships home
- [ ] Explorers returned from non-cancellable missions
- [ ] S100 explorers rearmed to a combat Weapons allocation
- [ ] No critical ship stranded Exploring
- [ ] Flexible transfers completed
- [ ] Flexible combat ships switched to Fixed where the 4-tick conversion is worthwhile
- [ ] W/E/S checked
- [ ] Current Defence checked
- [ ] Shields and war controls reviewed
- [ ] Current target scans obtained
- [ ] Break Orders calculated
- [ ] Retaliation losses calculated
- [ ] Replacement Power reserved
- [ ] Train affordable Cadets before war; trained Cadets survive defeat/respawn
- [ ] Replacement cadets reserved for immediate construction needs
- [ ] Metal / Deuterium / Iridium reserve checked
- [ ] Alliance target order understood
