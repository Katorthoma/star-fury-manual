# Raid reference

!!! note "Round-specific: Horizon LIII"
    The ranges and Intel caps on this page are Horizon LIII values. Re-check them when a new round starts.

Target ranges can change when the Raider Dock is strong enough to move a target into its **HIGH range**.

| Raid | Normal / lower Attack-Defence range | Known HIGH Attack-Defence range | Territory | Target limit |
|---|---:|---:|---|---:|
| Trade Fleet | 3,450–7,500 | 3,600–8,250 | None | None |
| Trade Convoy | 11,500–16,200 | 12,000–18,600 | None | None |
| Pirate Outpost | 34,500–46,400 | 36,000–51,200 | Land + Asteroids | 2/day |
| Sector Station | 74,750–87,750 | 78,000–100,750 | None | None |
| Galaxy Station | 110,000–137,500 | 121,000–148,500 | None | None |
| Pirate Stronghold | 190,000–250,000 | 199,500–270,000 | Land + Asteroids | 2/day |
| Universal Station | 275,000–337,500 | 287,500–350,000 | None | None |

The overall empire raid limit is **3 raids per day**, with a **6-hour cooldown between raids**.

## LOW-target Intel caps

When a raid target is still in its **LOW range**, its target Intel/Probe value will not exceed the following cap:

| Raid | Maximum LOW-target Intel |
|---|---:|
| Trade Fleet | 300 |
| Trade Convoy | 3,000 |
| Pirate Outpost | 15,000 |
| Sector Station | 24,000 |
| Galaxy Station | 42,000 |
| Pirate Stronghold | 60,000 |
| Universal Station | 120,000 |

!!! question "HIGH-range Intel"
    HIGH-target Intel behavior is not yet confirmed. HIGH targets may use a different scaling model, or they may continue to use fixed values. Until that is verified, use the Intel value shown by the raid interface.
