# Evidence and accuracy

Star Fury has been running in different forms for roughly 25 years. Old documentation remains easy to find, and an obsolete rule can still sound completely plausible.

This manual therefore separates stable mechanics from values that can change by round, administrator action, empire state, or incomplete evidence.

## How to read certainty

**Confirmed** means Star Fury states the mechanic directly or repeated play has reproduced it cleanly enough to treat it as a rule.

**Calculated** means the value follows mathematically from confirmed inputs.

**Round-specific** means the value is valid for the named round but may change later.

**Unverified** means the evidence is incomplete, contradictory, or not isolated well enough to publish as a rule.

Historical values appear only when they help current planning and are labeled as historical.

!!! warning "The game is authoritative"
    If Star Fury displays a different dynamic cost, timer, limit, or effect, use the value shown by the game. Round systems such as Alliance Catch Up are intentionally adjustable.

## Editorial convention

Unless a page says otherwise, prose describes V5 mechanics as they work in Horizon LIII. Confirmed rules are stated directly rather than repeatedly prefaced with words such as *current* or *observed*.

Round-specific values and unresolved mechanics are called out where they matter.

## Sources

The manual is built from the V5 interface, controlled in-game tests, repeated player observations, and older community material only when it still agrees with V5.

When evidence conflicts, newer interface behavior and controlled tests take precedence.


## Report an error

If a mechanic or value is wrong, open an issue in the GitHub repository. Include the page, the incorrect statement, and a screenshot or reproducible example when possible.
